# EventRegistrationSystem-

## Project Overview
A Java Spring Boot web application that allows users to register for events and view participant details using a unique ID.

## Features
- Event registration
- Search participants by ID
- Display event details
- Database integration

## Technologies Used
- Java, Spring Boot, Spring MVC
- JSP, HTML, CSS
- MySQL, Maven

## Application Workflow
1. Open the home page.
2. Register for an event by entering participant details.
3. Save the details in the database.
4. Search using participant ID to view details.
